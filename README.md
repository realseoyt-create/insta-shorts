# 세바꿀 자동화 (insta-shorts)

인스타그램 계정 **세바꿀(@sebaggul, 세상을 바꾸는 꿀팁)** 의 게시물을 자동으로 만들고, 주인이 승인한 것만 정해진 시각에 올리는 프로그램입니다.

- 매일 아침 소재를 모아 **릴스 영상**과 **카드뉴스**를 만들어 둡니다.
- 텔레그램 봇이 하나씩 보내 주면 **승인 / 거절 / 고칠 점 말하기**만 하면 됩니다.
- 승인한 것은 하루 두 번(낮 12시, 저녁 7시) 순서대로 올라갑니다.
- 승인 없이 올라가는 것은 없습니다.

작업 기록과 결정 사항은 [HANDOFF.md](HANDOFF.md)에 있습니다. 이어서 개발하는 사람(또는 AI)은 그 문서를 먼저 읽으세요.

---

## 1. 맥으로 옮기기

깃허브에는 **프로그램(코드)만** 올라가 있습니다. 열쇠(`.env`)와 지금까지 만든 게시물(`data`, `out`)은 비밀이거나 용량이 커서 따로 옮깁니다.

### ① 윈도우 PC에서 먼저 끄기

두 컴퓨터에서 동시에 켜면 텔레그램 봇이 서로 충돌하고, 같은 게시물이 두 번 올라갈 수 있습니다. **맥에서 켜기 전에 윈도우 쪽을 반드시 끄세요.**

- `npm start`를 실행한 창을 닫습니다. (지킴이 `run.mjs`를 끄면 서버도 같이 꺼집니다.)

### ② 맥에 두 가지 설치

| 설치할 것 | 받는 곳 | 왜 필요한지 |
|---|---|---|
| Node.js (LTS 버전) | https://nodejs.org | 프로그램을 돌리는 엔진 |
| Google Chrome | https://www.google.com/chrome | 영상·카드 그리기, 사이트 화면 찍기 |

### ③ 코드 내려받기

깃허브 저장소 페이지에서 초록색 **Code → Download ZIP**을 눌러 받아서 풉니다. (터미널이 익숙하면 `git clone`도 됩니다.)

### ④ 따로 옮긴 것 넣기

윈도우 PC에서 아래 세 가지를 맥으로 옮겨(USB, 구글 드라이브 등) 방금 푼 폴더 **안에** 넣습니다.

| 옮길 것 | 내용 | 없으면 |
|---|---|---|
| `.env` | 모든 열쇠(API 키, 토큰) | 아무것도 동작하지 않음. `.env.example`을 복사해 새로 채워야 함 |
| `data` 폴더 | 게시물 목록, 텔레그램 연결, 찾아 둔 사이트 | 처음부터 다시 시작 (봇도 다시 연결) |
| `out` 폴더 | 이미 만들어 둔 영상·카드 | 검토 대기 중인 것들을 다시 만들어야 함 |

`.env`는 이름이 점으로 시작해서 맥 파인더에서 안 보일 수 있습니다. 파인더에서 `Cmd + Shift + .`을 누르면 보입니다.

### ⑤ 실행

터미널(응용 프로그램 → 유틸리티 → 터미널)을 열고:

```
cd 폴더를_여기에_끌어다_놓기
npm install
npm start
```

- `npm install`은 처음 한 번만 합니다(몇 분 걸림).
- 브라우저에서 http://localhost:3200 을 열면 관리 화면이 나옵니다.
- 화면 위쪽에 "봇 연결됨", "자동 제작 09:00", "자동 발행 12:00, 19:00"이 보이면 정상입니다.

### ⑥ 맥이 잠들면 멈춥니다

이 프로그램은 **켜져 있는 동안만** 만들고 올립니다. 맥이 잠들면 그 시각의 제작·발행을 건너뜁니다.

- 잠들지 않게 켜려면 `npm start` 대신: `caffeinate -is npm start`
- 노트북은 전원을 연결하고 덮개를 열어 두세요.
- 터미널 창을 닫으면 프로그램도 꺼집니다.

## 2. 날마다 돌아가는 흐름

| 시각 | 하는 일 |
|---|---|
| 09:00 (`SCHEDULE`) | 소재 수집 → 요즘 뜨는 사이트 찾기 → "이번 주 소식" 카드 → 꿀팁 영상 → 카드뉴스 → 촬영 기획 채우기. 검토 대기 + 발행 예약이 8건(`STOCK_TARGET`) 이상이면 쉽니다 |
| 수시 | 텔레그램 봇이 검토할 것을 **하나씩** 보냄. 버튼으로 ✅ 승인 / ❌ 거절 / ⏭ 나중에, 또는 고칠 점을 글로 보내면 고쳐서 다시 보냄 |
| 12:00, 19:00 (`POST_TIMES`) | 승인한 것을 하나씩 인스타그램에 올림 (소식 카드 먼저, 그다음 승인한 순서) |
| 올린 뒤 | 봇이 게시물 주소를 알려 주고, 프로필 링크 페이지를 갱신 |

## 3. 만드는 게시물 종류

| 종류 | 설명 |
|---|---|
| 꿀팁 영상 (릴스) | 해외·국내 인기 쇼츠에서 **주제만** 참고해 새 대본을 쓰고, 음성·자막·배경 영상을 붙임 |
| 카드뉴스 | 표지 + 내용 5~7장 + 마무리. 장마다 내용에 맞는 사진 |
| 이번 주 소식 카드 | 할인·팝업·축제·공연 소식. 뉴스 제목을 근거로 쓰고 근거 기사를 함께 보여 줌 |
| 사이트 추천 카드 | 요즘 유튜브에서 소개된 사이트 + 확인해 둔 사이트 목록에서만 고름. 사이트 화면을 장 전체에 채우고 제목을 스티커처럼 얹음 (수·토요일 자동) |
| 직접 촬영 영상 | AI가 장면별 촬영 안내를 써 주면 찍어서 올림 → 음성·자막·편집이 붙음 |

## 4. 텔레그램 봇 명령

| 보내는 말 | 하는 일 |
|---|---|
| (버튼) ✅ / ❌ / ⏭ | 승인 / 거절 / 나중에 보기 |
| 고칠 점을 글로 | 그 부분만 고쳐서 다시 보냄 (예: "2번 장 제목 더 짧게") |
| `/news` | 이번 주 소식 카드 바로 만들기 |
| `/sites` | 사이트 추천 카드 바로 만들기 (`/sites 공부할 때`처럼 방향을 붙여도 됨) |
| `/card 주제` | 그 주제로 카드뉴스 만들기 |
| `/status` | 검토 대기·발행 예약 현황 |
| `/next` | 다음 검토할 것 보내기 |
| `/help` | 명령 목록 |

## 5. 열쇠 (`.env`)

값은 `.env`에만 넣습니다. 깃허브나 채팅에 올리지 마세요. 항목별 설명은 [.env.example](.env.example)에 있습니다.

| 항목 | 용도 | 필수 |
|---|---|---|
| `GEMINI_API_KEY` | 대본 쓰기, 검수, 사진 고르기 (무료 한도 안에서 사용) | 필수 |
| `YOUTUBE_API_KEY` | 소재 수집, 요즘 뜨는 사이트 찾기 | 필수 |
| `PIXABAY_API_KEY` | 배경 영상·사진 | 필수 |
| `CLOUDINARY_CLOUD`, `CLOUDINARY_PRESET` | 올리기 전 파일을 잠시 맡겨 두는 곳 | 발행에 필수 |
| `IG_USER_ID`, `IG_ACCESS_TOKEN` | 인스타그램 발행 (토큰 만료: 2027-01-10) | 발행에 필수 |
| `TELEGRAM_BOT_TOKEN` | 검토·승인 봇 | 권장 |
| `GITHUB_REPO`, `GITHUB_TOKEN` | 프로필 링크 페이지 자동 갱신 | 선택 |
| `KOPIS_KEY`, `TOUR_API_KEY` | 공연 예매 순위, 축제 정보 (소식 카드에 사용) | 선택 |
| `SCHEDULE`, `POST_TIMES`, `STOCK_TARGET` | 제작 시각, 발행 시각, 쌓아 둘 개수 | 기본값 있음 |
| `BROWSER_PATH` | 크롬 위치를 못 찾을 때만 직접 적음 | 보통 불필요 |

## 6. 파일 구성

| 파일 | 역할 |
|---|---|
| `run.mjs` | 지킴이. 서버가 꺼지면 5초 뒤 다시 켬 (`npm start`) |
| `server.mjs` | 관리 화면 서버, 시각 맞춰 제작·발행, 텔레그램 시작 |
| `lib.mjs` | 핵심: 수집, 대본, 검수, 렌더, 발행 |
| `telegram.mjs` | 텔레그램 봇 (검토 요청, 버튼, 명령) |
| `links.mjs` | 프로필 링크 페이지 만들기 (GitHub Pages) |
| `tts.mjs` | 음성 만들기 |
| `admin.html` | 관리 화면 |
| `src/` | 영상·카드 디자인 (`Shorts.tsx`, `Card.tsx`, `Bee.tsx`) |
| `brand/` | 꿀벌 캐릭터 "바꿀이" 이미지 (`node brand.mjs`로 다시 만듦) |
| `data/` (깃에 없음) | `tips.json` 게시물 목록, `telegram.json` 봇 연결, `sites.json` 찾아 둔 사이트, `server.log` 기록 |
| `out/` (깃에 없음) | 만들어진 영상·카드 이미지 |

## 7. 바꾸기 쉬운 부분

| 바꿀 것 | 위치 |
|---|---|
| 수집 검색어 | `lib.mjs`의 `CONFIG` |
| 첫 문장(후킹) 규칙 | `lib.mjs`의 `HOOK_RULES` |
| 영상 대본 규칙 | `lib.mjs`의 `writeScript` |
| 카드뉴스 규칙 | `lib.mjs`의 `writeCards` |
| 소개할 사이트 목록 | `lib.mjs`의 `SITE_POOL` (이름, 주소, 설명을 한 줄 추가) |
| 요즘 뜨는 사이트 검색어 | `lib.mjs`의 `discoverSites` |
| 카드 디자인 | `src/Card.tsx` |
| 영상 디자인 | `src/Shorts.tsx` |
| 음성 | `.env`의 `TTS_PROVIDER`, `TTS_VOICE` |
| 제작·발행 시각 | `.env`의 `SCHEDULE`, `POST_TIMES` |

코드를 고친 뒤에는 서버를 다시 켜야 반영됩니다(영상·카드 디자인도 마찬가지). 만드는 중인 게시물이 없을 때 하세요.

## 8. 알아둘 점

- **원본을 가져다 쓰지 않습니다.** 다른 계정·영상에서는 주제만 참고하고 문장·영상·사진은 새로 만듭니다. 인스타그램은 재게시 위주 계정을 추천에서 뺍니다.
- **AI가 쓴 금액·날짜·제도·주소는 틀릴 수 있습니다.** 검수를 한 번 거치지만, 봇이 보여 주는 "확인할 점"은 승인 전에 꼭 보세요.
- **자동 접속을 막는 사이트는 우회하지 않습니다.** 화면을 못 찍으면 사진이나 글로 대신하고, 직접 찍은 화면을 관리 화면에서 올릴 수 있습니다.
- **Gemini 무료 한도**는 모델마다 하루 단위로 정해져 있고 한국 시간 오후 5시쯤 풀립니다. 한도가 차면 다른 모델로 넘어가고, 모두 차면 그날은 제작이 멈춥니다.
- **Edge 음성**은 무료지만 비공식 경로입니다. 막히면 `TTS_PROVIDER`를 바꾸세요.
- **텔레그램 코드에는 `AbortSignal`을 쓰지 마세요.** 윈도우의 Node 26.13에서, 큰 파일을 보내는 중에 같은 곳으로 가는 요청을 중단시키면 프로그램이 기록 없이 꺼지는 문제가 있었습니다(`telegram.mjs` 주석 참고).
- Remotion은 일정 규모 이상의 회사에서 쓰면 유료 라이선스가 필요합니다: https://www.remotion.dev/docs/license

## 9. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 관리 화면이 안 열림 | 터미널에서 `npm start`가 켜져 있는지. `data/server.log` 마지막 줄 |
| 봇이 조용함 | 다른 컴퓨터에서 같은 봇으로 서버가 켜져 있지 않은지. 관리 화면 위쪽의 봇 상태 |
| 영상·카드가 안 만들어짐 | 크롬이 설치돼 있는지. 못 찾으면 `.env`에 `BROWSER_PATH=/Applications/Google Chrome.app/Contents/MacOS/Google Chrome` |
| "한도" 관련 오류 | Gemini 무료 한도. 오후 5시 이후에 다시 시도 |
| 발행 실패 | 봇이 이유를 알려 줍니다. 세 번 실패하면 그 게시물은 멈춤. 인스타 토큰 만료 여부 확인 |

## 10. 서버에 올려 24시간 돌리기 (선택)

```
docker build -t insta-shorts .
docker run -d --name insta-shorts --restart unless-stopped \
  -p 3200:3200 --env-file .env \
  -v insta-data:/app/data -v insta-out:/app/out \
  insta-shorts
```

- `.env`에 `ADMIN_PASSWORD`를 꼭 넣고 HTTPS를 붙이세요.
- 메모리 2GB 이상을 권장합니다. 이 방식은 아직 실제로 돌려 보지 않았습니다.
