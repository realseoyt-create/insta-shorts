# 세바꿀 설명형 쇼츠 지시서 (템플릿)

`{{ }}`만 채워서 에이전트 한 명에게 통째로 준다. 한 줄 호출: "이 지시서를 처음부터 끝까지 읽고 그대로 수행한다. 이 지시서가 유일한 지시다. 승인 창이 뜨거나 막히면 멈추고 무엇에 막혔는지 보고한다."

너 혼자 소재에서 소리 든 세로 영상까지 만든다. 대본 작가, 검수자, 조립 담당이 없다. 훅, 문장, 화면, 움직임, 소리를 한 머리로 정한다. 정해진 컷 틀은 없다. 아래 "세바꿀다움"만 지키면 나머지는 네 판단이다.

이 영상은 인스타그램 계정 **세바꿀(@sebaggul, 세상을 바꾸는 꿀팁)** 에 릴스로 올라간다. 배경 영상에 자막을 얹는 평소 영상과 달리, **숫자·비교·원리·절차를 화면의 그림과 움직임으로 이해시키는 편**이다.

## 채울 것

- 제목: {{제목}}
- 소재와 원문: {{소재 문서 경로}}, 원문 사본 {{사본 경로들}}. 소재 요약과 사본이 다르면 사본이 맞다.
- 만들 것: {{첫 15초 견본 | 30~45초 전편}}
- 작업 폴더와 출력 파일 이름: {{폴더}}, {{mp4 이름}}
- 참고할 취향(규칙이 아니라 근거): 싫다고 한 것 {{...}}, 좋다고 한 것 {{...}}, 실물 {{레퍼런스 시트 경로}}

## 시청자

릴스를 넘기는 한국의 20~40대. 살림, 먹거리, 생활용품, 절약, 생활에 쓰는 사이트에 관심이 있다. 전문 용어를 모른다. 첫 2초 안에 "나한테 해당되는 얘기"라고 느끼지 못하면 넘긴다.

## 어떤 소재가 이 형식에 맞는가

- 돈 계산 (요금 구간, 1년 합계, 환급), 둘의 비교 (A 대 B), 원리 (왜 그렇게 해야 하는지), 절차 (신청 3단계, 기한).
- 손동작을 봐야 아는 꿀팁(청소, 세탁, 정리)과 물건 소개는 이 형식으로 만들지 않는다. 받은 소재가 그런 것이면 만들지 말고 그렇게 보고한다.
- AI·IT·개발 주제는 이 계정에서 다루지 않는다.

## 세바꿀다움 (지킬 것)

- 색: 따뜻한 검정 `#17110A`, 꿀 노랑 `#FFB400`, 크림 `#FAF6EC`, 글자 `#1C1509`. 강조색은 한 장면에 하나만 더 쓴다.
- 글꼴: 제목은 Jua, 본문은 Pretendard, 손글씨 느낌이 필요하면 Gaegu.
- 꿀벌 캐릭터 "바꿀이": `{{insta-shorts 폴더}}/brand/bee.png`. 첫 화면이나 마지막 화면에 한 번은 나온다. 내용을 가리지 않는다.
- 마지막 화면: 한 줄 정리 + "@sebaggul". 팔로우를 조르는 문구는 한 번만.
- 말투: 친구에게 알려 주듯 짧은 존댓말("~해요", "~하세요"). 한 문장에 한 가지만.
- 화면 가장자리: 위 220px, 아래 420px에는 중요한 글자를 두지 않는다 (인스타그램 단추와 캡션에 가린다).

## 어길 수 없는 것

- **숫자, 날짜, 금액, 제도 이름, 인용은 사본에 있는 것만 쓴다.** 사본에 없는 수치를 계산해 만들었으면 계산식을 기록에 적는다. 확인할 수 없으면 화면에 쓰지 않는다.
- 화면에 숫자나 인용이 나올 때는 출처를 같은 화면에 작게라도 보여 준다 (기관 이름이나 기사 제목).
- 과장("무조건", "100%", "역대급"), 효능 단정("낫는다", "살이 빠진다"), 써 보지 않은 것을 써 본 것처럼 말하기, 확인되지 않은 "내돈내산"은 쓰지 않는다.
- 훅이 약속한 것을 영상 안에서 반드시 보여 준다. 지어낸 불이익으로 겁주지 않는다.
- 다른 사람의 영상·사진·음악을 가져다 쓰지 않는다. 그림은 직접 그리고, 소리는 직접 합성한 것만 쓴다. 사람 얼굴을 한 가상 인물은 만들지 않는다.
- 내레이션 길이는 어림하지 말고 받은 소리를 재서 맞춘다.
- 규격: 1080×1920, 30fps, mp4(H.264 + AAC), 100MB 이하, 길이 3초~3분. 첫 프레임이 표지처럼 보이게 만든다 (0.8초 지점이 썸네일이 된다).

## 쓸 수 있는 것 (이 환경에 있는 것)

{{이 칸은 영상을 만드는 컴퓨터의 환경에 맞게 채운다. 예:}}

- 영상: {{HyperFrames 등. 먼저 읽을 스킬과 돌아가는 본보기 폴더}}
- 무거운 일(렌더, 헤드리스 Chrome): {{감싸는 명령}}. 화면 캡처: {{도구}}
- TTS: {{방식과 하루 한도. 한도에 걸리면 다음 모델로 넘어가고 어느 모델로 받았는지 기록}}
- 효과음과 배경음은 직접 합성한 것만. 생성 이미지와 직접 그린 SVG는 가능.

## 하지 않을 것

- `rm`으로 지우지 않고 덮어쓴다. 승인 창이 뜨면 멈추고 보고한다. git 커밋, 쿼터 조회, 다른 편 폴더 열기는 하지 않는다.
- 인스타그램에 직접 올리지 않는다. 올리는 것은 계정 주인의 승인을 거쳐 세바꿀 서버가 한다.
- 진행은 작업 폴더 `PROGRESS.md`에 한 줄씩, 시작과 끝에 `date`로 시각을 적는다.

## 출력

1. mp4
2. 0.5초 간격 프레임 시트(한 장 30프레임). 직접 열어 보고 고칠 것이 보이면 고쳐 다시 렌더한다(렌더 최대 3회).
3. 기록 html 하나: 내레이션 전문, 훅을 이렇게 잡은 이유, 화면에 쓴 숫자와 인용의 원문 표현과 출처, ffprobe 값, 소리 점검(끝이 안 잘렸는지, 목소리 대 배경음 음량), TTS 모델, 렌더 횟수, 걸린 시간, 못 한 것.
4. **세바꿀 서버에 넘기기.** 아래 두 파일을 `{{insta-shorts 폴더}}/inbox/`에 저장한다. 글 파일을 먼저, 영상을 나중에 저장한다. 서버가 20초마다 이 폴더를 보고 검토 대기에 넣고, 계정 주인의 텔레그램으로 검토 요청을 보낸다.
   - `{{이름}}.json`
     ```json
     {
       "title": "목록에 보일 제목 (영상의 훅)",
       "caption": "인스타그램에 올라갈 글. 첫 줄은 훅을 받는 한 문장. 이어서 영상 내용을 번호로 정리하고, 마지막 줄에 출처를 적는다.",
       "hashtags": "#세바꿀 #꿀팁 (주제에 맞는 것 3~5개)",
       "sources": [
         { "text": "화면에 쓴 숫자나 인용을 그대로", "source": "기관 이름이나 기사 제목", "url": "https://" }
       ],
       "notes": "계정 주인이 승인 전에 알아야 할 것 (확인하지 못한 점, 발음이 걱정되는 낱말 등)"
     }
     ```
   - `{{이름}}.mp4`
   - 같은 컴퓨터가 아니면 폴더 대신, 계정 주인이 영상을 텔레그램의 세바꿀 봇에게 보내면 된다 (20MB까지. 영상에 붙인 글의 첫 줄이 제목, 나머지가 캡션).

## 마지막 메시지

영상 경로와 길이, 시트 경로, 내레이션 전문, inbox에 넣은 파일 이름, 못 한 것.
